# Contributing

**Read this first:** agentlathe has a [single maintainer and no review commitments](README.md#project-status). Issues and pull requests are best-effort — they may go unanswered or be closed without action, and there is no support channel. Small, focused PRs with tests have a real chance of being merged; large ones may never be reviewed. The one channel that is always read is the private security report described in [SECURITY.md](SECURITY.md#reporting-a-vulnerability).

The license is MIT, so forking is a first-class option rather than a last resort. If you want to take this somewhere the maintainer is not going, fork it — that is the intended path, not a failure of one.

If you do open a PR: a change in behavior without a corresponding test will not be merged, and CI has to be green. Everything you need to work on the code — setup, scripts, test levels, formatting and commit conventions — is in [docs/DEVELOPING.md](docs/DEVELOPING.md).

By participating you agree to abide by the [Code of Conduct](CODE_OF_CONDUCT.md).
